## 📁 Repository Directory & Experiment Breakdown

### 🔹 Unit I: Introduction
* **11259A200_exp1.c: Implementation of Basic Array Operations**
  * *Purpose:* Performs continuous-memory primitive array operations covering index insertion, deletion, and full matrix sequential traversal.
* **11259A200_exp2.c: Building a Dynamic Employee Record System**
  * *Purpose:* Constructs a custom record layout tracking system using structure pointers and runtime allocation functions.

### 🔹 Unit II: Stacks and Queues
* **11259A200_exp3.c: Implementation of Stack and Expression Conversion**
  * *Purpose:* Manages algebraic operators over stack limits to dynamically convert standard Infix strings into Postfix syntax.
* **11259A200_exp4.c: Postfix Expression Evaluation using Stack**
  * *Purpose:* Parses numerical postfix notations, utilizing computational stack pushing and popping to return exact mathematical totals.
* **11259A200_exp5.c: Implementation of Simple Queue using Array**
  * *Purpose:* Standardizes FIFO operations using linear tracking indicators to execute sequential Enqueue and Dequeue logic.
* **11259A200_exp6.c: Implementation of Priority Queue using Unordered Array**
  * *Purpose:* Organizes element queues where items are retrieved and processed based on strict relative priority values rather than arrival order.

### 🔹 Unit III: Linked Lists
* **11259A200_exp7.c: Implementation of Singly Linked List**
  * *Purpose:* Configures non-contiguous heap memory structures to allow fully dynamic node insertions, middle drops, and traversals.
* **11259A200_exp8.c: Implementation of Circular Queue using Linked List**
  * *Purpose:* Merges queue and pointer architectures by linking the terminal node back to the front block to avoid memory fragmentation.

### 🔹 Unit IV: Trees
* **11259A200_exp9.c: Implementation and Traversal of a Binary Search Tree**
  * *Purpose:* Builds hierarchical node partitions to perform clean recursive In-order, Pre-order, and Post-order deep path printouts.

### 🔹 Unit V: Graphs, Sorting and Hashing
* **11259A200_exp10.c: Implementation of Graph Search Algorithms**
  * *Purpose:* Map out node connections using queue-driven Breadth-First Search (BFS) and stack-driven Depth-First Search (DFS) pathways.
* **11259A200_exp11.c: Implementation of Bubble, Selection and Heap Sorts**
  * *Purpose:* Compares runtime ordering efficiency by tracking value swaps across Bubble, Selection, and max/min Heap tree structures.
* **11259A200_exp12.c: Implementation of Hashing with Collision Resolution**
  * *Purpose:* Implements key hashing algorithms that resolve index conflicts using systematic step-by-step Linear Probing.
